# Angular target

Use this when the user picks Angular. Moving from React means rewriting components as standalone Angular components with templates. Translate behavior; do not embed React.

## Scaffold

- `npx @angular/cli@latest new <name> --routing --style=<css|scss>` with the current stable Angular. Accept the defaults the CLI generates for that version (standalone components, application builder, zoneless change detection or zone.js as generated). Do not add SSR or prerendering unless the user wants it for SEO. Then it is `ng add @angular/ssr`, with prerendering for static routes.
- Tailwind: follow the Tailwind guide for the Angular version. Use the same major version and config as the original, with `content` including `./src/**/*.{html,ts}`.
- Lint: `ng add angular-eslint` (with template accessibility rules); Prettier. Tests: the CLI's test runner for components with logic.

## Structure

```text
src/
├── app/
│   ├── app.ts / app.html             root component: header, <router-outlet>, footer
│   ├── app.config.ts                 providers: router, etc.
│   ├── app.routes.ts                 top-level routes, lazy features
│   ├── core/                         singletons: theme service, site config (only if needed)
│   ├── layout/                       site-header, site-footer components
│   ├── shared/ui/                    reusable presentational components
│   └── features/<feature>/
│       ├── <feature>.routes.ts       when the feature has several routes
│       ├── pages/<feature>-page.ts
│       ├── components/hero-section.ts …
│       └── data.ts
├── assets/ or public/                as generated by the CLI version
├── styles.css                        global styles and design tokens
└── index.html  main.ts
```

Follow the file naming the CLI generates for the installed version (newer versions drop the `.component` suffix). Use one component per file: template and styles inline for small components, separate files when they are long.

## Translating React to Angular

| React (Lovable) | Angular |
| --- | --- |
| Function component | `@Component({ selector, imports: [...], template })` standalone class |
| Props | `input()` / `input.required()` signals |
| Callback props | `output()` |
| `children` | `<ng-content>` (with `select` for named regions) |
| `useState` | `signal()`; `computed()` for derived values |
| `useEffect` | `effect()`, `afterNextRender` for DOM work, `DestroyRef` for cleanup |
| Context / shared hooks | `@Injectable({ providedIn: 'root' })` service with signals |
| `{cond && …}` / `.map()` | `@if` / `@for (item of items; track item.id)` |
| `className` + `cn()` | `[class]`/`[ngClass]` bindings; resolve Tailwind conflicts explicitly |
| `<Link to>` | `routerLink`, `routerLinkActive` |
| lucide-react | lucide-angular |
| shadcn/ui (Radix) | spartan/ui or Angular CDK (overlay, a11y, dialog); Angular Material only if the user chose it |
| framer-motion | CSS transitions or Angular animations |
| react-hook-form + zod | Reactive forms with typed `FormGroup` and validators (same rules and messages) |
| next-themes | `ThemeService` with a signal, the same storage key, and a class on `document.documentElement` |

Use RxJS for event streams where it fits (debounced search). Use signals for component state.

## Routing

- `provideRouter(routes, withInMemoryScrolling({ anchorScrolling: 'enabled', scrollPositionRestoration: '<match original>' }), withComponentInputBinding())`.
- Same paths as the original. Lazy features: `loadComponent: () => import('./features/about/pages/about-page').then(m => m.AboutPage)`, or `loadChildren` for feature route files.
- Catch-all `{ path: '**', component: NotFoundPage }`, last.
- Hash anchors: `routerLink="/" fragment="contact"` for cross-page anchors; a plain `href="#contact"` only where the original used one on the same page.
- SPA fallback on the static host, unless SSR or prerendering is used.

## Head and SEO

Route `title` property (or a `TitleStrategy` for a suffix pattern) to match the original titles exactly; the `Meta` service for description and OG tags per route; global tags stay in `index.html`. Prerendering through `@angular/ssr` only on request.

## Build and deploy

`ng build` → `dist/<project>/browser`. Serve that folder with a static server for the parity run (with SPA fallback). Document the host configuration.
